# Python Tasks

Решение двух задач на Python.

## Задание 1: Средние буквы слова

Программа находит и выводит среднюю букву (если количество букв нечётное) или две средние буквы (если чётное).

**Пример:**
- `word = 'test'` → `es`
- `word = 'testing'` → `t`

## Задание 2: Dating-сервис MVP

Программа создаёт пары из двух списков (юноши и девушки), сортируя имена по алфавиту. Если количество людей в списках не совпадает, выводится предупреждение.

**Пример:**
```
boys = ['Peter', 'Alex', 'John', 'Arthur', 'Richard']
girls = ['Kate', 'Liza', 'Kira', 'Emma', 'Trisha']
```

**Результат:**
```
Идеальные пары:
Alex и Emma
Arthur и Kate
John и Kira
Peter и Liza
Richard и Trisha
```
